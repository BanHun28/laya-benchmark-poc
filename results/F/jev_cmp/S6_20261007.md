## Anomalies / notes

- There are 0 numeric mismatches with the session summaries. 1 wording issue: "about 25 minutes later" in verdict 1 of `S1b_summary.md` is 16\~23 minutes (median 20 minutes) in the request records. It agrees with "about 15\~30 minutes apart" in `S1b_run_card.md`. summary.md uses the recorded values.
- Tables not cross-checked row by row because their formats differ: the T2 Jev confusion matrix (S1 described it only in prose) and the T8 confidence table (S5 uses a different column layout). For the 4 session summaries that omit the Router row, the rerun output was checked to show a Router row identical to the english row, and the english row was cross-checked.
- The best Laya runner is a post-hoc choice made after seeing the results, which favors Laya. The pooled tests with a fixed runner point the same way (english 40/21, multilingual 58/16, Router 42/21).
- The figures are static PNG/SVG, so only a light-mode version was made. Teal (contrast 2.74) and yellow (2.11) are below 3:1 against the light background, so direct labels inside the bars and the summary.md tables are provided alongside.
- build asserts that `jev_runs_all.jsonl` equals the concatenation of the six session request logs.
