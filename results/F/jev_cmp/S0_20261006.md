- **T4**: n=40 < 77 labels, so `stratify` gives 1 row each to the first 40 labels. The label order was therefore shuffled with `random.Random(13).shuffle` instead of being alphabetical (assumption). The distractors consume a single `Random(13)` in row (id) order (the upstream MASSIVE convention of 1 stream per language). Reading it as "a new Random(13) for each item" would make the distractors of all rows nearly identical, so that interpretation was discarded (assumption).

  - Following decision (b), it was rebuilt with upstream's key-only rendering (`{k.replace("_", " "): None}`, bench_apps.py:120-122, build_benchmark_nb.py:460). expected is also the spaced key, up to 48 characters.

**Interpretation caveats**
- **The T3 sample is easy for Laya english.** Running the upstream suite (first 600 rows, same question) through the same pipeline gives 0.5733 / ECE 0.3237. This equals the published 0.5733 / 0.3238 (`research/results/t4_colab_benchmark.json` `en.emotion`), so the pipeline reproduces upstream. The full 2,000-row test gives 0.595. The 40 T3 rows also have identical choice, probabilities and answer_confidence in the 2,000-row run (40/40). However, scoring this class composition with the per-class recall of the full split gives an expected value of 0.506, while 0.750 is observed. With this sample only paired comparisons with Jev are made, and the difference from the published figures is not generalized. The seed was not changed.
- **T5**: upstream uses the first 600 rows (natural distribution, true 0.617) and we use a balanced 20/20, so the majority baseline is 0.5.
- **T7 en**: multilingual (0.85) is higher than english (0.70). This is the opposite direction from upstream's 20-option result, but n=20 and the CIs overlap.
- **typed-decisions checkpoint**: it was fine-tuned on this benchmark's train split (BENCHMARKS.md:332). It is not a zero-shot comparison line.
