## Anomalies / notes

- **No errors.** With no 5xx, 429 or limit message, neither the retry rule (1 retry after 65 s) nor the stop rule fired.
- **Score rendering check.** The S1 recipe enters the full form `options` strings (`level i: …`) in the rubric fields of score questions (`criteria` in the S1 run 1 request body). Laya also reads score questions rendered as `level %d: %s` (`laya/common.py` `render_options`), so the same strings were entered in the T6 rubric fields. `s4_prep.py:75` asserts that the Laya `render_options` output equals the form options. The on-screen bar labels therefore look like "0 — level 0: very negative".
- **`jev_cmp.py` changes (minimal).**
  1. `parse_single_display` (`jev_cmp.py:128-131`): in single mode the Score card is headed SCORE, not DECISION, so if there is no DECISION it looks for SCORE. Regression: the parse results of all 190 existing single-mode dumps (S1\~S3) are the same as before the change. For the first T6 dump (run 1), the screen parse was checked separately before recording.
  2. The set argument of `analyze` now accepts commas to pool several sets (`:318-320`; the Laya reports are also read per set and pooled, `:334-337`). With two sets it outputs a cross-language consistency table over the same ids (`crosslang_lines`, `:373-375`, `:465-479`).
  3. Branch for score sets, `score_lines` (`:338-342`, `:482-573`): argmax-level accuracy (primary), rounded E[level] accuracy (secondary, half-up like the display rule's `Math.round`), E[level] MAE, signed error and within ±1, 5-level Brier, ECE (argmax p), McNemar under both rules, paired bootstrap of the MAE difference (2,000 resamples, seed 13), predicted-level distribution and first/last level selection, correct answers and mean E per gold level, confusion matrices (Jev, Laya english), Jev confidence, and a per-row table. The Laya values equal accuracy·brier·ece·mean_confidence·score_mae·within_1_level in `laya_summary.json` `results.T6_sst5_40`.
  4. `request_lines` (`:454-462`): appends "answered by" (rows per checkpoint) to the Router report line. Regression: the outputs of `analyze S1 T2`, `S2 T3`, `S3 T4`, `S3 T5` and `S4 T7 en·de` differ only in the suffix of this one line and are otherwise byte-identical. `t1 S1,S2` is byte-identical.
- **Host wall-clock step.** The wall − mono offset changed once between runs 77 and 78, from +14 to −38 ms (−52 ms). The gap guard and dump matching use the monotonic axis, so there is no effect. As in S3, `click_epoch_ms`·`click_kst` are values on the monotonic axis.
- **Maximum gap 31.1 s (run 2).** Time for manually checking the first T6 screen parse and taking the screenshot after run 1; unrelated to the site.
- **Judgments involving interpretation (to be verified).** Treating the 2 ids of Jev's T7 errors as label-boundary cases, and the 1 T6 row off by 2 levels as a mixed-sentiment sentence, are judgments made from reading the sentences. Scoring used the dataset labels as they are.
- `docs/` and `data/evals/` were not edited. The Laya models were not run. The Playwright MCP output directory in the repository root (1 snapshot, 1 console log) was copied to `raw/mcp/` and then deleted.
