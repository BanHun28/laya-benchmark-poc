## Anomalies / notes

- **No errors.** With no 5xx · 429 · limit message, neither the retry rule (1 retry after 65 s) nor the stop rule fired.
- **Raw-character state check.** Laya reads a dict state as `json.dumps(state, ensure_ascii=False)` (`laya/common.py` `serialize_state`). Before the run, we asserted that the form `state_text` equals this string 100/100 and contains no `\u` escapes (`s5_prep.py`). States containing non-ASCII: T7 60/60, T8 13/40. The body sent by the browser was also byte-identical to the form payload (`ensure_ascii=False`, compact).
- **`jev_cmp.py` changes (minimal).**
  1. `cmd_analyze` reads comma-joined sessions together (`jev_cmp.py:321-323`), because the 5-language table needs the S4 en · de records together with the S5 ja · zh-CN · ko records.
  2. The condition that output cross-language consistency only for 2 sets was widened to 2 or more (`:374`). With 3 or more sets, `crosslang_lines` hands over to `crosslang_multi` (`:472-473`). `crosslang_multi` (`:485-527`) outputs per-language and pooled accuracy, the language penalty vs en, per-language exact McNemar, cross-language consistency (same label as the first language, same label in all languages, mean pairwise language agreement, correct · wrong in all languages), and per-id right/wrong patterns and label counts. The usage line (`:5`) was also fixed.
  3. Regression: the outputs of `analyze S1 T2`, `S2 T3`, `S3 T4`, `S3 T5`, `S4 T6`, `S4 T7 en`, `S4 T7 en,de`, `S5 T7 ja · zh-CN · ko` and `S5 T8` are byte-identical before and after the change. `analyze S4,S5 T7 en,de` is also byte-identical to `analyze S4 T7 en,de`, and `t1 S1,S2` matches its output as of S4.
- **Instrumentation change (minimal).** `instrument.js` is the same as in S4, with only the version tag (S5) and the session-cap check (`ready()` returns ok=false at 110 or more Run clicks) added. The session ended at 100, so the cap never triggered.
- **Degenerate T8 AUROC CI.** Jev's p(true) separates the 40 rows perfectly, so the percentile bootstrap yields [1.000, 1.000]. This does not mean a population AUROC of 1. The CIs of the AUROC differences are also optimistic, because the variance on the Jev side is 0.
- **Host wall clock.** The wall − mono offset was −3 \~ +20 ms, with small steps at runs 75 → 76 (+5 ms) and 76 → 77 (+10 ms). The gap guard and dump matching use the monotonic axis, so there is no effect. As in S3 · S4, `click_epoch_ms` · `click_kst` are values on the monotonic axis.
- **Judgments involving interpretation (to be verified).** Treating 1 T7 zh-CN error as a translation dropout and the 1 id wrong in every language as a label-boundary case, and dividing the T8 errors into "role · task instruction type vs explicit override", are judgments made from reading the sentences. Scoring used the dataset labels as they are.
- `docs/` and `data/evals/` were not edited. The Laya models were not run. The Playwright MCP output directory in the repository root (1 page-load snapshot, 1 console log) was copied to `raw/mcp/` and then deleted.
