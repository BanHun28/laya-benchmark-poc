## 이상 / 주석

- **1차 세션 502.** 두 번째 Run(row 37)이 HTTP 502로 끝났다. 페이지 문구는 "Jev is temporarily unavailable." / "Unable to evaluate"이고 콘솔에 `status of 502`가 찍혔다. 입력값은 정상이었다. 당시 규칙대로 즉시 중단했다. 08:20에 복구를 확인한 뒤 재개했다.
- **2차 세션.** 23회 모두 200이었고 콘솔 오류는 0건이었다. 429·rate-limit 문구·captcha는 두 세션 모두 보이지 않았다.
- **검증.** run 25회 모두 Run 전 precheck(해시 대조)를 통과했다. 성공한 24회는 모두 DOM dump와 accessibility snapshot이 일치했다. 1차 세션 레코드 2건에는 나중에 `attempt: 1`을 넣었고, evidence로 다시 만들면 바이트 단위로 같다.
- **정리.** Playwright MCP 출력 디렉터리는 승인에 따라 다른 실행이 남긴 파일까지 포함해 통째로 삭제했다. 필요한 snapshot과 콘솔 로그는 먼저 `results/F/jev_raw/`로 복사했다.
