## 이상 / 주석

- **경고 원문 (서버 로그 31-32행)**, english 슬롯 lazy 로드 때 1회:
  ```
  .venv/lib/python3.12/site-packages/laya/router.py:594: RuntimeWarning: laya: this checkpoint ships invalid temperatures or values outside [0.5, 5]; using choice:11+=0.10058280825614929 -> 0.5. Treat confidence from the affected entries as uncalibrated.
    agent = Agent(repo, **kwargs)
  ```
  원인은 base english `models/laya/rl_agent_config.json`의 `temperature_by_options["choice:11+"] = 0.1006`이다. 11지선다 이상 choice에만 걸리고, ft-v1(`temperature_by_options` 없음)과 router_v1(8지선다)에는 영향이 없다.
- 점검 스크립트 경고(테스트 전용): `StarletteDeprecationWarning: Using httpx with starlette.testclient is deprecated; install httpx2 instead.`
- 브라우저 콘솔: 키 없이 연 첫 로드와 키를 지운 점검의 401, 서버를 내린 뒤 5초 폴링의 `ERR_CONNECTION_REFUSED`만 있었고 JS 예외는 없었다. 첫 로드의 `favicon.ico` 404는 `<link rel="icon" href="data:,">`로 없앴다.
- 정적 파일 캐시: Starlette `StaticFiles`가 `Cache-Control`을 보내지 않아 Chrome이 수정 전 `index.html`을 휴리스틱 캐시로 보여 준 적이 있다. UI를 고친 뒤 확인할 때는 강력 새로고침이나 `?v=` 쿼리가 필요하다(스크린샷은 최종 파일로 다시 찍었다).
- ft-v1 확신도 분포: 9개 예시의 p가 0.92\~0.96에 몰려 있고 T 0.907과의 여유는 0.017\~0.05다. 2,917행 곡선에서도 T 0.90 → 0.95 사이에 coverage가 0.919 → 0.386으로 떨어진다. 문구가 조금 바뀌거나 정밀도가 바뀌면(fp16 등) ROUTE ↔ FALLBACK이 쉽게 갈린다는 뜻이라, T는 이 체크포인트·스키마에만 유효하다는 기동 시 대조를 유지해야 한다.
- 일반 모드 질문(고객 문의 라우팅, 프리셋 등)도 `multilingual` 슬롯을 쓰므로 ft-v1이 답한다(도메인 8 파인튜닝 체크포인트). YNAT 망각은 없었지만(+0.021) 다른 질문 세트의 품질은 측정하지 않았다.
- `/poc/decide`의 `min_confidence: null`은 T로 처리한다(생략과 같음). 05 §3 스케치(`body.get("min_confidence")`)는 null이면 abstention 보고를 끄는데, §5가 "min_confidence=T로 abstention 보고를 켠다"고 하므로 후자를 따랐다.
- MetricsHook은 503을 볼 수 없다. 503은 `create_app`의 admission에서 predict 전에 나기 때문이다.
