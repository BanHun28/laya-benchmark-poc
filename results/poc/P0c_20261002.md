> P0c: a Korean topic/domain routing zero-shot measurement that previews PoC scenario C (05_poc_plan.md:33 "RAG domain index router") and Track B (03_benchmark_plan.md §7). ## Anomalies / notes
- Verbatim warning. Each of the 2 english runs produced 1: `.venv/lib/python3.12/site-packages/laya/router.py:594: RuntimeWarning: laya: this checkpoint ships invalid temperatures or values outside [0.5, 5]; using choice:11+=0.10058280825614929 -> 0.5. Treat confidence from the affected entries as uncalibrated.` (next line `agent = Agent(repo, **kwargs)`). It is raised at load time. So it does not apply to the confidence of YNAT english (7 options, choice:6-10 bucket 1.00002), only to the confidence of scenario18 english (choice:11+). The 8 multilingual runs had 0 warnings. When the analysis script decoded with the english tokenizer, transformers printed 1 `clean_up_tokenization_spaces` notice; it came only from the display decode for R5 and is unrelated to the measurements.
- Assumption 1 (YNAT quota): the distribution pattern of the 04:333 MANIFEST example (72,72,72,71,71,71,71) was applied as is to the "ceil(N/k) cap" of 04:111. The first 2 labels in ClassLabel order get 15 and the rest 14. Every label has at least 15 rows, so the backfill rule was not triggered.
- Assumption 2 (interpreting `_en-desc`): the request wording "Korean instructions unchanged but descriptions in English" can be read two ways. Interpretation 1 changes only the descriptions to English relative to base (instructions=en). It fits the single-suffix convention at 04:318, and for MASSIVE it reproduces the upstream setup exactly. This is what `_en-desc` was built as. Interpretation 2 (ko-instr + en-desc) was added as `_ko-instr_en-desc`. The difference between the two interpretations is in R2 rows 4 and 9 (YNAT Δ 0, scenario Δ −0.05, both n.s.).
- Assumption 3: the Korean instructions wording and the YNAT English descriptions are not defined in the docs, so the operator of this run wrote them (builder constants). The Korean particles were chosen by pronunciation (headline → "헤드라인은", utterance → "어터런스는").
- Assumption 4: the first 100 MASSIVE rows contain 3 exact-duplicate pairs (rows 52/53 "청소기 작동 시켜줘", 66/67 "내일 비가 올까", 86/87 "화장실 불 꺼 줘"; each pair has the same label). The "same 100 rows" rule (04:123, 04:143) took priority, so they were kept. See doc inconsistency 3 below.
- The MASSIVE scenario definition was checked.
