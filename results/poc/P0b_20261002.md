## Anomalies / notes
- Verbatim warning. 1 in each of the 2 english runs (same as P0): `.venv/lib/python3.12/site-packages/laya/router.py:594: RuntimeWarning: laya: this checkpoint ships invalid temperatures or values outside [0.5, 5]; using choice:11+=0.10058280825614929 -> 0.5. Treat confidence from the affected entries as uncalibrated.` (next line `  agent = Agent(repo, **kwargs)`). 0 in the 10 multilingual runs. The rest of stderr is only the HF hub `Fetching 5 files: 100%` progress bar (cache hit). No tokenizer-patch warning or CPU fallback.
- No re-runs. After the V8 definition was added to the builder, the V0..V7 files were regenerated but were byte-identical (sha256 == report dataset_sha256), so the reports already run remain valid as they are.
- Independence of question rows: with the same model and the same state format, questions with identical definitions gave identical answers even across variants (78 (run pair, question) combinations, argmax flip 0, max abs(Δp) 0.0001). So V8 multilingual was predicted exactly before the run as V6 intent + V2 binary + V0 for the rest, and the result was the same.
