분할 규칙은 작업 지시대로다. ko/en 쌍 MASSIVE 파일(`*_massive_domain_8`, `*_massive_intent_20opt`)과 같은 행 순서의 domain_8 변형은 데이터 행 index가 짝수면 dev, 홀수면 test다. 이때 ko·en 행마다 expected와 `scenario:` 태그가 일치함을 assert했다(500/500, 100/100). 나머지 파일은 `int(sha256(json.dumps(state, ensure_ascii=False, sort_keys=True)), 16) % 2`가 0이면 dev, 1이면 test다. 변형 파일은 base와 state·expected 순서가 같음을 assert한 뒤 dev 행만 복사했다(원 헤더 + `# split: dev ...` 한 줄, 데이터 줄은 바이트 그대로). 같은 규칙은 `scripts/metrics_extra.py`의 `row_splits`에 구현돼 있다.

## 이상 / 주석
- 경고 원문 (laya-evals 런 23개: english·typed-decisions 21개 전부와 english를 로드한 Router 2개 `router_ko_nsmc_sentiment`, `router_ko_kmhas_type_8`):
  `.venv/lib/python3.12/site-packages/laya/router.py:594: RuntimeWarning: laya: this checkpoint ships invalid temperatures or values outside [0.5, 5]; using choice:11+=0.10058280825614929 -> 0.5. Treat confidence from the affected entries as uncalibrated.`
  typed-decisions도 english와 같은 `choice:11+=0.10058280825614929` 값을 출하한다. multilingual 런에는 경고가 없다. 런별 목록은 summary §10에 있다.
- 보조 스크립트 경고 (B_head_budget.py, 모델 런 아님): `[transformers] Ignoring clean_up_tokenization_spaces=True for BPE tokenizer TokenizersBackend. The clean_up_tokenization post-processing step is designed for WordPiece tokenizers and is destructive for BPE (it strips spaces before punctuation). Set clean_up_tokenization_spaces=False to suppress this warning, or set clean_up_tokenization_spaces_for_bpe_even_though_it_will_corrupt_output=True to force cleanup anyway.`
- 머신 공유: 같은 머신의 다른 작업(Llama-3.1-8B, CPU 약 105%)이 동시에 돌았다. 정확도에는 영향이 없고(CPU fp32 결정적), 리포트의 latency 열은 해석하지 않는다. 전원은 AC였다.
- Router auto의 비한글 행 3개(NSMC row 140 `wjehdlhs;lhlshlsifhow;`, row 187 `I am the doctor`, K-MHaS type_8 row 181 영어 문장)가 english로 라우팅됐다. 규칙대로의 동작이다. 평가셋에 한글이 없는 행이 섞여 있다는 점은 데이터 품질 메모로 남긴다.
- english·typed-decisions는 한국어 설명을 옵션당 22\~30토큰에서 자른다(`B_head_budget.md`). 이들의 한국어 수치와 `en_massive_domain_8` english "기준점"은 잘린 옵션의 값이다.
- domain_8의 dev/test 차이(0.560 vs 0.492)는 index parity 분할의 scenario 구성 차이 때문이다. test 절반은 alarm 1행(dev 4행), calendar 16행 0정답, play 19행 5정답이다.
- ECE의 percentile bootstrap CI는 위로 편향돼 있어, 작은 ECE에서는 점추정이 하한 밖에 놓일 수 있다. 지표성으로만 읽는다.
- 문서 변경 관찰: docs/03, 04, 07의 mtime이 16:38(첫 런 16:43 직전)이다. 데이터와 MANIFEST의 해시는 46개 리포트와 일치하므로 측정 대상은 바뀌지 않았다.
- 재실행 없음. 46/46 exit 0.
