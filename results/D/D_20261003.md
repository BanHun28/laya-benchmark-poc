## Anomalies / notes

- The warning texts are in summary §11. In short: the `RuntimeWarning: laya: this checkpoint ships invalid temperatures or values outside [0.5, 5]; using choice:11+=0.10058280825614929 -> 0.5. Treat confidence from the affected entries as uncalibrated.` for english·typed-decisions, 4 ONNX export UserWarnings, and 1 ORT quantization pre-processing recommendation. There were no tokenizer patch warnings and no CPU fallback.
- **Deviations from the plan.**
  - (1) The field reference in the D1 noul instruction text was changed from ``ticket.messages[0].text`` to ``text``.
  - (2) `--states short,long` was added to D2 (the 03:241 command does not specify states).
  - (3) D1b (forced fp32), D1c (paced) and D7b (ORT 10 threads) were measured in addition, to support the interpretation of the verdicts.
  - (4) The first version of D8 peak sampled after the warm-up and so had no post-load baseline. `memory_child` was therefore fixed and a supplementary run was done. Both files were kept, and their peak values are the same.
  - (5) The `--gap-ms` option was added after the D1\~D3 runs. Its default of 0 matches the previous behavior.
  - (6) The OS file cache could not be cleared for the 1st D3 run (`sudo purge` not available). So "cold" means process-cold, disk-cache-warm.
- Script size: bench_latency_local.py has 295 lines, above the instructed range (\~150-250), because it holds the four modes D1·D2·D3·D8 and the run-card helpers. The other two scripts import the run card, sha and evals_rows from this file.
- **Differences from expectations.**
  - The MPS gain is only 2\~3x.
  - MPS gains almost nothing from more questions or from batching.
  - Under intermittent traffic, both MPS and CPU pay an idle penalty. MPS becomes 2.2\~3.6x slower with a 100 ms gap.
  - ONNX is slower than torch CPU.
  - The causes (DVFS, AMX) are hypotheses and were not isolated.
- No 503 occurred in D6, so the Retry-After compliance path was never executed. An overload run (concurrency ≥ 17 or MPS 3q ≥ 23 RPS) was not run.
- Following the instructed command, the D7 reports scored all 500 ynat rows (including the 255 test rows). The accuracy is used only for path comparison (03 §3.2).
